## 宿題

- 取り組んだレベル：基礎 
- やったこと：app/tools.py の search_glossary の docstring の「query には調べたい用語を1つだけ入れる」を「query には調べたい用語をまとめて入れる」に書き換えた（変更はこの1か所のみ）。同じ質問「LoRAとQLoRAの違いは？」を、変更前と変更後に --trace 付きで実行して比べた。変更前に「検索回数は1回に減るはず」と予想した。

- 結果：変更前は search_glossary が2回呼ばれ、引数は 'LoRA' と 'QLoRA' が別々だった（tool_calls=2、input_tokens=1196、output_tokens=180）。変更後は1回だけ呼ばれ、引数は 'LoRA QLoRA' とまとめられていた（tool_calls=1、input_tokens=885、output_tokens=178）。予想通り検索回数は1回に減り、入力トークンも減った。ただし変更後の tool return の表示が途中で省略されていたため、QLoRAの定義が検索結果に含まれていたかは画面からは確認できなかった（最終回答にはQLoRAの説明も含まれていた）。

- 気づき・疑問：docstring は人間向けのコメントではなくモデルへの指示として働いていて、1フレーズ変えるだけでツールの呼ばれ方が変わることが、tool_calls の数字で確認できた。一方で、trace の文章自体は難しくて追いきれず、トークン数のような数字の読み方もまだよく分かっていない。検索結果の中身を画面の表示だけで完全に確かめるのは難しいと感じた。
